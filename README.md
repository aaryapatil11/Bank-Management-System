# 🏦 Bank Management System

## 📌 Project Overview

The **Bank Management System** is a web-based application developed using HTML, CSS, and JavaScript. It provides a simple and interactive interface for managing bank accounts and performing basic banking operations.

The application allows users to create accounts, view account details, search accounts, deposit money, withdraw money, check balances, and delete accounts.

## 🚀 Features

- **Dashboard:** Displays total accounts, total balance, deposits, and withdrawals.
- **Create Account:** Create a new bank account with account number, account holder name, and initial balance.
- **View All Accounts:** Display all registered accounts in a table.
- **Search Account:** Search for an account using its account number or holder name.
- **Deposit Money:** Deposit money into an existing account.
- **Withdraw Money:** Withdraw money with balance validation.
- **Check Balance:** View the current balance of an account.
- **Delete Account:** Remove an account from the system.
- **Data Persistence:** Stores account information using browser Local Storage.
- **Responsive Design:** Provides a user-friendly interface on different screen sizes.

## ⚙️ How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Navigate through the dashboard.
5. Create accounts and perform banking operations.
